# CodePath CYB101: Intro to Cybersecurity

This repository contains my hands-on cybersecurity projects completed throughout **CodePath's CYB101: Intro to Cybersecurity** course. Each project demonstrates practical experience with Linux, cryptography, SSH authentication, password security, exploitation, malware analysis, steganography, and threat analysis through real-world cybersecurity exercises.

---

## Overview

Throughout this course, I completed a series of practical cybersecurity projects designed to strengthen foundational security knowledge and develop hands-on technical skills. Each project includes documentation of the tools used, commands executed, screenshots, technical concepts learned, and key takeaways.
